🚀 QUICK DEPLOYMENT STEPS:

1. Create HF Space
   URL: https://huggingface.co/spaces
   - Click "Create new Space"
   - Name: fake-news-detector
   - SDK: Streamlit
   - License: MIT

2. Clone Space to Local
   git clone https://huggingface.co/spaces/krishtewatia/fake-news-detector

3. Copy All Files
   - Copy app_hf.py, main.py, requirements.txt
   - Copy entire pipeline/ directory
   - Copy start.sh, README_FOR_HF.md → README.md
   - Copy config.py, .env.example

4. Add Secrets in HF Space Settings
   - OPEN_ROUTER_KEY
   - NEWSAPI_KEY
   - SERPAPI_KEY

5. Push to HF
   git add .
   git commit -m "Deploy fake news detector"
   git push

6. Wait 5-10 minutes for deployment

7. Access Your Space
   https://huggingface.co/spaces/krishtewatia/fake-news-detector
